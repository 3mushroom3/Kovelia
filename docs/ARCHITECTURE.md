# Архитектура сайта Kovelia

## Принципы

1. **Статика по умолчанию.** Все страницы собираются как SSG для каждой локали. Контент из CMS кэшируется (`revalidate: 3600` + тег `sanity`) и обновляется вебхуком, так что сайт быстрый и дешёвый в хостинге.
2. **Сайт работает без внешних сервисов.** Пока Sanity, Telegram или Resend не настроены, сайт собирается и открывается: контент берётся из `src/content/` (услуги, цены и кейсы из каталога компании), заявки пишутся в консоль (только в dev).
3. **Один вход для каждого слоя.** Контент берётся из `@/lib/cms`, env из `@/lib/env`, навигация из `@/i18n/navigation`, SEO из `@/lib/seo`. Благодаря этому замена CMS или i18n-библиотеки затрагивает один модуль.
4. **UI не знает, откуда пришли данные.** Компоненты получают доменные типы (`Service`, `Project`), а не документы Sanity.

## Поток запроса

```
Браузер → proxy.ts (next-intl)
            /services     → rewrite  /ru/services   (ru без префикса)
            /en/services  → как есть
            /ru/services  → redirect /services
        → app/[locale]/layout.tsx   (dynamicParams=false: неизвестная локаль сразу 404)
        → app/[locale]/<page>/page.tsx
            → lib/cms → Sanity (кэш, тег "sanity")  | src/content
```

## Слои

| Папка                 | Ответственность                                        | Может импортировать                      |
| --------------------- | ------------------------------------------------------ | ---------------------------------------- |
| `app/`                | Роутинг, метаданные, сборка страниц из секций          | всё                                      |
| `features/<x>/`       | Законченная фича: UI, server action, схема, интеграции | `components`, `lib`, `i18n`              |
| `components/sections` | Крупные блоки страниц, получают данные пропсами        | `components/ui`, `lib/cms/types`, `i18n` |
| `components/layout`   | Шапка, подвал, переключатели                           | `components/ui`, `lib/site`, `i18n`      |
| `components/ui`       | Примитивы без бизнес-логики                            | `lib/utils`                              |
| `lib/`                | Инфраструктура: cms, env, seo, утилиты                 | `i18n`, `content`                        |

## Решения

| Решение                                       | Почему                                                                                                           |
| --------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| Next.js App Router                            | SSG/ISR, Server Components, SEO из коробки, server actions для форм                                              |
| next-intl, `localePrefix: "as-needed"`        | Типобезопасные ключи, готовый proxy, чистые URL для основной аудитории (ru)                                      |
| Sanity                                        | Гибкие схемы, бесплатный тариф, встраиваемая Studio, вебхуки                                                     |
| Поля `{ ru, en }` в Sanity                    | Один документ на сущность, перевод виден рядом с оригиналом, fallback через `coalesce`                           |
| Tailwind v4 + CSS-токены                      | Тема меняется одной правкой в `globals.css`, тёмная тема через переменные                                        |
| Единый стиль с KOVELIA Agro (zernovik.online) | Один бренд для всех продуктов: ink-зелёный, мятные акценты, паттерн с плюсиками, градиент логотипа               |
| motion + `<ViewTransition>`                   | Анимации появления и переходы между страницами без ручного управления монтированием, с поддержкой reduced motion |
| Server Action + zod для формы                 | Работает без JS, одна схема для клиента и сервера, никаких отдельных API-роутов                                  |
| Telegram / Resend через `fetch`               | Без SDK-зависимостей, каналы включаются через env                                                                |

## Безопасность

- Секреты используются только на сервере (`lib/env.ts` помечен `server-only`).
- Заголовки безопасности задаются в `next.config.ts`. CSP пока не настроен: добавить после того, как определится аналитика.
- Форма защищена серверной валидацией, honeypot-полем и ограничением длины полей. Если появится спам, добавить rate limit (Upstash) или Cloudflare Turnstile.
- Вебхук ревалидации проверяет подпись Sanity.

## Деплой

Рекомендуется Vercel: нулевая конфигурация, preview на каждый PR. Альтернатива — self-hosting через `output: "standalone"` в Docker (см. `node_modules/next/dist/docs/01-app/02-guides/self-hosting.md`).

Переменные окружения перечислены в `.env.example`. В production обязательны `NEXT_PUBLIC_SITE_URL` и минимум один канал доставки заявок.
